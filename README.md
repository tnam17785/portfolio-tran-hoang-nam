# Trần Hoàng Nam — Portfolio v5

Single-page cyber portfolio · pure HTML/CSS/JS

## Repo
https://github.com/tnam17785/portfolio-tran-hoang-nam

## Features
- Dynamic particle background (REPEL / ATTRACT / ORBIT modes)
- Boot sequence, aurora, matrix overdrive
- Custom cursor + trails + click graffiti
- Glitch name, typing text, scramble on hover
- **Live age** (seconds since 02/01/2009)
- **Card flip** (double-click about cards)
- **Secrets counter** ◆ 0/7
- Sound toggle (♪)
- Command palette `Ctrl+K`
- HUD `H`, Konami overdrive, themes
- Scroll progress, section dots, toasts
