# Trần Hoàng Nam — Portfolio

Trang giới thiệu bản thân tĩnh, tối giản nhưng đầy hiệu ứng.

## Tính năng

- Nền particle network động (canvas)
- Hiệu ứng glitch text
- Custom cursor
- Typing animation
- Glass cards + 3D tilt
- Smooth scroll reveal
- Responsive

## Chạy local

Mở `index.html` trực tiếp hoặc dùng live server.

```bash
npx serve .
```

## Tech

- Pure HTML / CSS / JS
- Google Fonts (Orbitron + Rajdhani)
