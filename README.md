# Trần Hoàng Nam — Portfolio v4

## New in v4
- **Boot sequence** (skippable) on first load
- **Command Palette** — `Ctrl+K` or `/`
- **Interactive Terminal** — type `help`, `overdrive`, `theme cyan|magenta|lime|gold`, `whoami`, `status`, `glitch`, `hud`, `clear`
- **Toast / Achievements** when discovering secrets
- **HUD telemetry** — press `H` (mode, particles, FPS, theme)
- **Section dots** on the right
- **Theme switcher** (cyan / magenta / lime / gold)
- All v3 features kept (Konami, scramble, name explode, matrix, clock...)

## Shortcuts
| Key | Action |
|-----|--------|
| Ctrl+K / / | Command palette |
| H | Toggle HUD |
| ↑↑↓↓←→←→BA | Overdrive |
| Double-click logo | Overdrive |
| Click name | Scatter letters |
| Type in terminal | Commands |

## Run
Open `index.html` or `npx serve .`
